# 🧠 Mental Health Prediction

A Machine Learning-based project focused on analyzing the impact of social media usage on students' mental health.

## 📌 Project Overview

Mental health is an important aspect of student well-being. Excessive or unhealthy social media usage may influence students' mental health, sleep patterns, academic performance, and daily activities.

This project explores the relationship between social media habits and students' mental health using data analysis and machine learning techniques.

## 🎯 Objectives

- Analyze the impact of social media usage on students.
- Explore relationships between social media habits and mental health scores.
- Perform data preprocessing and exploratory data analysis.
- Develop a machine learning model to predict mental health scores.
- Present insights through a Streamlit-based application.

## 📊 Dataset

**Dataset:** Student Social Media and Mental Health Impact

- Total Records: 5,000
- Total Features: 13
- Target Variable: `Mental_Health_Score`

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/satyamsaket9508-wq/ScrollWell.git
```

2. Navigate to the project directory:

```bash
cd ScrollWell
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the Streamlit application:

```bash
python -m streamlit run main.py
```
